W6.2 singleInstance interop: an instance of tag pre-rust-rewrite (TypeScript bun:ffi single instance)
and an instance of this branch (single instance in Rust through the binding) hand off to each other
in both directions.

Setup (no worktree; <TEMP> is the system temp directory, <REPO> this checkout):
$ mkdir -p <TEMP>/sweetview-w62-old <TEMP>/sweetview-w62-driver
$ git archive pre-rust-rewrite | tar -x -C <TEMP>/sweetview-w62-old
$ (cd <TEMP>/sweetview-w62-old && bun install)        # 36 packages installed
$ (cd <REPO> && just native)                          # the rewrite's binding

Each side runs `bun -e <script>` with its own tree as the working directory, so
`@n1h/sweetview-native` resolves to that tree's package. The scripts:

primary:
  import { pumpEvents, singleInstance } from "@n1h/sweetview-native";
  let got;
  const lock = await singleInstance({ appId, urlSchemes: ["svtest"], args: [], onSecondInstance: (e) => { got = e; } });
  console.log("READY isPrimary=" + lock.isPrimary);
  while (!got && Date.now() < deadline) { pumpEvents(); await Bun.sleep(10); }
  console.log("RECEIVED " + JSON.stringify(got ?? null));
  lock.dispose();

secondary:
  import { singleInstance } from "@n1h/sweetview-native";
  const lock = await singleInstance({ appId, urlSchemes: ["svtest"], args: ["--from", who, "svtest://open/42"] });
  console.log("RESULT " + JSON.stringify({ isPrimary: lock.isPrimary, handedOff: lock.handedOff }));
  lock.dispose();

The driver (<TEMP>/sweetview-w62-driver/driver.ts) starts the primary, waits for READY, runs the
secondary, then waits for the primary to exit:
$ cd <TEMP>/sweetview-w62-driver && bun driver.ts <TEMP>/sweetview-w62-old <REPO>
