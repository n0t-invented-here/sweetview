- `WebView.openTab<M, E>(window: Window, options: TabOptions<M>): Promise<Tab<M, E>>` (L923-931). Throws "sweetview: tabs driver is not loaded" if no driver registered. Docs: Windows creates a child pane in the custom tab-strip frame, attaches WebView2, hooks accelerator keys, `NewWindowRequested`, `NavigationCompleted`, native right-click menus, tear-off, merging. macOS creates an NSWindow in AppKit tabbing (`addTabbedWindow:ordered:`), attaches WKWebView, keeps the tab bar visible, hooks new-window requests and load errors, detaches message handlers on close. Both: HTTP(S) `target="_blank"`/`window.open()` opens a tab after the current one in the tab's current window, other schemes dropped; URL tab with failed navigation shows "This site did not open" page. Opening a tab does not show a hidden tabbed window unless `showOnReady`. Throws `WebView.openTab requires a Window created with { tabs: true }`, `cannot open tab in a disposed window`, `native tabs are not supported on <platform> (win32 and darwin only)`, or any `WebView.attach` error.

## Behaviour: tabs on Windows

- `new Window({ tabs: true })` -> `createTabbedWindow` (`N/win32/window.ts` L532) -> `createFrameWindow` with `stripHeight: STRIP_HEIGHT` (40 DIP), size 1040 x (720+40) DIP when no bounds, `systemDark` from registry `AppsUseLightTheme` when appearance is "system".
- Frame: class `SweetviewTabFrame`, style `WS_OVERLAPPEDWINDOW | WS_CLIPCHILDREN` (minus `WS_THICKFRAME|WS_MAXIMIZEBOX` if not resizable); exStyle `WS_EX_LAYERED` (if opacity), `WS_EX_TOOLWINDOW` (hideFromTaskbar), `WS_EX_NOACTIVATE`. Caption removed in `WM_NCCALCSIZE`: DefWindowProc result kept but client top restored to original top (+ frame border when zoomed). Without bounds: outer size = DIP*dpi/96 + 2*border.x wide, + border.y tall; centered on primary work area (or at `at`). Topmost via `HWND_TOPMOST`. Dark via `DwmSetWindowAttribute(DWMWA_USE_IMMERSIVE_DARK_MODE=20)`.
- Strip pane: a `SweetviewTabPane` child (`WS_CHILD|WS_CLIPCHILDREN`) at (0,0, width, round(40*dpi/96)), shown at creation. Page area = client minus strip.
- Background painting: `WM_ERASEBKGND` fills with fixed colours: light strip #e9eaee / page #f9f9fb; dark strip #292a30 / page #15161a (solid brushes cached per colour).
- Host creation is lazy: first `openTab` calls `ensureHost` (`S/tabs/win-tabs.ts` L475). It requires `meta.tabs`, a live window, and `getTabFrame(hwnd)`. Registers `onWindowDispose(window, disposeHost)`, frame callbacks (activate/resized/moved), then `WebView.attach` on `Window.fromHandle(frame.stripPane)` with assets `index.html` (via `indexHtml`, title `meta.title || "Tabs"`, an inline `<script>` setting `data-theme` when the frame appearance is explicit), `main.js` = STRIP_JS, `main.css` = STRIP_CSS, and `uiMethods` `strip.*`. `holdWindowNativeDispose(window)` is held during the attach. On success `frame.layout()`; on failure the half-built host is forgotten so a later openTab retries. Concurrent `openTab` calls await `host.stripReady`.
- Strip `uiMethods` (L572-599): `strip.state` (sets `stripUp`, returns `StripState`), `strip.select/close/new/move/detach/menu/focus/drag/resize/minimize/maximize/closeWindow` (all deferred with `setTimeout(0)` via `fromStrip`, which skips if host closed and finally calls `focusPage`), `strip.scrolled` (stores `scrolledBy`), `strip.dark(d)` (defers `frame.setSystemDark(d)`; returns `d` for "system" frames else `frame.isDark()`).
- State push: `pushStrip` emits event `strip` with `{ tabs:[{id,title}], selected, maximized, active }` whenever anything changes, only after the strip called `strip.state`.
- Per tab (`winTabsDriver.openTab` L660): id from a monotonic counter starting at 1; initial title = `options.title` ?? URL hostname (or url) ?? `Tab <id>`. `frame.createPane()` creates a hidden child pane sized to the page area; `Window.fromHandle(pane)` is the borrowed window; `WebView.attach(paneWin, {...options, title, [tabAttachHooks]})`. Then `frame.placePane(pane)` (MoveWindow pane and its first child to page area). Throws "the tab's webview has no browser controller" if `beforeNavigate` did not capture it.
- `beforeNavigate` for each tab: gets `ICoreWebView2Controller` via `webview_get_native_handle(kind=2)`; wraps `raw.navigate`/`raw.setHTML` to bump `navEpoch`; subscribes accelerator keys; subscribes `NewWindowRequested`; for URL tabs binds `__sweetviewTabTitle`, injects `FOLLOW_TITLE` init script (reports `document.title` on DOMContentLoaded, head mutations, and load), and subscribes navigation failure.
- Insertion: after `options.after` if it is in this host, else after `host.selected`, else at end. New tab becomes selected, is presented, strip pushed, `onTabSelect` emitted.
- Switching (`selectTab`/`present`, L162-184): `put_IsVisible(true)` on the new controller, `frame.showPane(pane)` (place + `SetWindowPos(... SWP_SHOWWINDOW 0x40)`), then hide previous pane (`SW_HIDE`) and `put_IsVisible(false)`; title synced; focus moved to page.
- Title: `syncWindowTitle` sets frame title to `"<tab title> - <baseTitle>"` (or just tab title when baseTitle empty; or baseTitle when no tab selected). `baseTitle` is `meta.title` at host creation. `renameTab` trims; empty becomes `Tab <id>`.
- Closing (`closeTab`, L209-239): if not `force` and it is the last tab, sends `WM_CLOSE` to the frame (onClose listeners run, or the window disposes when none); if the window was destroyed, `disposeHost`; the tab stays if a listener intercepts. Otherwise: mark closed, unlist (selection moves to the tab at the same index, else the previous), present the new selection, hide pane, forget controller, run handler removers, `webview.dispose()`, `wrappedWin.dispose()`, `DestroyWindow(pane)`, sync title, push strip, emit `onTabClose`, emit `onTabSelect` for the new selection. If no tabs remain, `WM_CLOSE` as above. `tab.close()` defers `closeTab` with `setTimeout(0)`; `tab.dispose()` calls `closeTab(record, true)` synchronously.
- Direct `tab.webview.dispose()`: `beforeDestroy` hook calls `releaseDisposedTab` (unlist and hide now; pane destroy, re-present, strip, events and last-tab WM_CLOSE deferred one tick).
- Reordering: strip `strip.move {id,index}` -> splice into `host.tabs` at clamped index, push strip.
- Tear-off (`strip.detach {id, held}`): if the tab is the window's only tab, the whole window is dragged (`dragByTab`); afterwards if the strip moved, `dropOnStrip` finds another visible host whose strip rect contains the cursor (in `hostOrder`, most recently activated first) and moves the tab there at `dropIndex(...)`. Otherwise a new tabbed `Window` is created (copying title, appearance, icon, resizable, topmost, opacity, hideFromTaskbar, noActivate, min sizes) at cursor minus `held*scale`, same size; tab events forwarded to the source window; the tab moves (`SetParent(pane, newFrame)` after `SW_HIDE`), `rebindFileDrop()`, `NotifyParentWindowPositionChanged`; new window shown; if left button still down, `dragByTab` on the new window. Source host with no tabs left is disposed.
- Context menu (`strip.menu`): over empty strip -> system menu (`GetSystemMenu`, items enabled per maximized state, default Close, `TrackPopupMenu(TPM_RIGHTBUTTON|TPM_RETURNCMD)`, then posts `WM_SYSCOMMAND`). Over a tab -> popup: "New tab\tCtrl+T", "Move tab to new window" (enabled >1 tab), "Merge all windows" (enabled >1 host), "Close tab\tCtrl+W", "Close other tabs" (enabled >1 tab).
- Merge (`mergeAllWindows(into?)`): target = given host or most recently active; moves every tab of every other host to the end of target (each source host disposed when emptied); reselects the previously selected tab; `frame.show()`.
- New-window requests: handler sets `Handled=TRUE`, then on a later tick, if the URL matches `^https?://`, opens a tab `{ url, after: thisTab }` in the tab's current window. Other schemes are dropped.
- Failed loads (URL tabs only): `onNavigationFailed` reports when the latest top-level navigation completes with `IsSuccess=false`, excluding `OperationCanceled(14)`, `ConnectionAborted(9)`, any HTTP status > 0, `about:`/`data:` URLs, and navigations superseded by a newer NavigationId or a newer host navigate/setHTML (`navEpoch`). The page is set synchronously inside NavigationCompleted with `raw.setHTML(loadFailedPage(url-or-options.url, reason))`. Reason text from a fixed table of `COREWEBVIEW2_WEB_ERROR_STATUS` values (1-18), default "The page could not be loaded.".
- Keyboard shortcuts (`shortcutFor`): Ctrl+T new; Ctrl+W, Ctrl+F4 close tab; Ctrl+Tab, Ctrl+PageDown next (wraps); Ctrl+Shift+Tab, Ctrl+PageUp previous (wraps); Ctrl+1..8 select index; Ctrl+9 last; Alt+F4 close window (closes every tab in turn). Modifier state read with `GetKeyState`. Only KEY_DOWN/SYSTEM_KEY_DOWN events. On tab webviews `Handled` is set only for matched shortcuts; on the strip webview `Handled` is always set to TRUE (the handler returns `true`). Action runs on a later tick.
- Focus: `focusPage` calls `ICoreWebView2Controller::MoveFocus(PROGRAMMATIC)` on the shown tab (or strip if none), only if the frame is the foreground window. On `WM_ACTIVATE` active, host moves to front of `hostOrder` and focuses on the next tick; strip `active` flag pushed.
- DPI: `WM_DPICHANGED` applies the suggested rect (`SetWindowPos`). Strip height and min size scale by `GetDpiForWindow/96`; frame border via `GetSystemMetricsForDpi(SM_CXSIZEFRAME/SM_CYSIZEFRAME + SM_CXPADDEDBORDER)`. `frame.scale()` = dpi/96 used for drop index and held offsets.
- Resizing: `WM_SIZE` (not minimized) relayouts strip pane and shown pane (and each pane's first child) and fires `onResized` (-> `Window.onResize`, strip `maximized` push when it changed). `WM_GETMINMAXINFO`: caller `minWidth/minHeight` applied as outer pixels as-is; default min = 560x420 DIP page + strip + frame edges. `WM_MOVE` -> `onMoved` -> `NotifyParentWindowPositionChanged` on strip and every tab controller, and `Window.onMove`.
- Strip-driven window chrome: `strip.drag` -> `frame.startDrag(held)` (repositions window so the held point is under the cursor when not zoomed, then `ReleaseCapture` + `WM_NCLBUTTONDOWN HTCAPTION`); `strip.resize {edge: top|top-left|top-right}` -> `startResize` (`WM_NCLBUTTONDOWN` with HT 12/13/14); both require left button down. `strip.minimize`/`maximize` -> `SW_MINIMIZE`/toggle `SW_MAXIMIZE`/`SW_RESTORE`; `strip.closeWindow` -> `WM_CLOSE`.
- Window dark mode: strip reports OS `prefers-color-scheme`; `setSystemDark` changes only "system" frames and invalidates frame and panes. `setDarkWindows(on)` updates every "system" frame.
- File drops: `WM_DROPFILES` on the frame -> `fireFileDrop` (DragQueryFileW / DragFinish). Drops over a tab's webview go through `WebView.attach`'s file-drop handler to `fileDropHost()` = tab's current logical window.

## Behaviour: tabs on macOS

- `new Window({ tabs: true })` -> `createVirtualTabbedWindow` (`N/darwin/window.ts` L689): `handle: null`; records `show/hide` (latest wins), `setBounds/moveTo/resize`, `setTitle`, `setTopmost` until a controller binds; default bounds {100,100,1040,720}; `scale()` 1; `setIcon`, `setClickThrough`, `setHitRegions` no-ops; event buckets local; `onFileDrop` toggles `controller.setFileDropEnabled`.
- First `openTab` -> `ensureHost` (`S/tabs/darwin-tabs.ts` L352): requires `meta.tabs` and not disposed; `installTabMenus()` once per menu bar; `createWindowTabs({ identifier: "sweetview.tabs.<n>", bounds, width||1040, height||720, minWidth??480, minHeight??320, appearance, resizable, topmost, opacity, hideFromTaskbar, noActivate, callbacks })`; then `bindHostToWindow` -> `bindDarwinTabGroup(backend, controller)` and `hooks.replay()`.
- Menus added (`installTabMenus`): File (inserted at index 1): "New Tab" `newWindowForTab:` Cmd+T, "Close Tab" `performClose:` Cmd+W. View: "Show All Tabs" `toggleTabOverview:` Cmd+Shift+\. Window: Minimize `performMiniaturize:` Cmd+M, Zoom `performZoom:`, separator, "Show Previous Tab" `selectPreviousTab:` Ctrl+Shift+Tab, "Show Next Tab" `selectNextTab:` Ctrl+Tab, "Move Tab to New Window" `moveTabToNewWindow:`, "Merge All Windows" `mergeAllWindows:`; set as `windowsMenu`.
- Each tab is an NSWindow of class `SweetviewTabWindow` (NSWindow subclass): style Titled|Closable|Miniaturizable (+Resizable unless `resizable:false`), `NSBackingStoreBuffered`, `setReleasedWhenClosed:NO`, frame from bounds, title, `setMinSize:` (outer points), `setAlphaValue:`, level `NSStatusWindowLevel` (25) if topmost, `NSWindowCollectionBehaviorIgnoresCycle` + app `Accessory` policy if hideFromTaskbar, appearance `NSAppearanceNameDarkAqua`/`Aqua` if explicit, `setTabbingIdentifier:`, `setTabbingMode: Preferred(1)`, `setNextResponder:` shared responder, observed notifications. Created hidden.
- `openTab` (L440): `createWindow(title)`, `openPage(nsWin)`, setTopmost, add to `host.attaching`, `Window.fromHandle(nsWin)`, `WebView.attach(wrappedWin, …)`; rollback on failure (detachPage + dispose webview, dispose wrapper, `group.discard`, `forgetPage`, release group if idle).
- `beforeNavigate` (macOS): installs new-window UIDelegate; for URL tabs binds `__sweetviewTabTitle`, injects the same `FOLLOW_TITLE` script, and installs `onLoadFailed`.
- Showing: if host visible, `showTab` with anchor = `after` (if shown, open, same host) else `activeTab(host)`; `group.show(nsWin, anchor ?? null, beforeShow)`. No anchor: window opens standalone with the host's frame (`setFrame:display:`), centered only when the group has no bounds. With anchor: `addTabbedWindow:ordered: NSWindowAbove`. Then `makeKeyAndOrderFront:` + `activateIgnoringOtherApps:YES` (or `orderFrontRegardless` when noActivate), then `keepTabBar` (calls `toggleTabBar:` if the group's tab bar is not visible). `focusWebView` makes the hosted WKWebView first responder. `onTabSelect` emitted. If host hidden: queued in `pendingShow`; first queued becomes `selectedBeforeShow`; flushed on `show()`.
- Switching: AppKit tab clicks; `NSWindowDidBecomeMainNotification` -> `onSelected` -> `onTabSelect`, and `keepTabBar` on next tick. `tab.select()`: `makeKeyAndOrderFront:` (or `setSelectedWindow:` on the `tabGroup` + `orderFrontRegardless` when noActivate); unshown tabs record `selectedBeforeShow`.
- Title: `tab.setTitle` trims (empty -> `Tab <id>`) and sets that NSWindow's title. `Window.setTitle` on the host sets the active tab's title through `tab.setTitle`.
- Closing: close button / Cmd+W / `performClose:` on `SweetviewTabWindow` -> `tabCloseRequests` callback -> `onCloseRequest`: returns true (veto) only if it is the host's last tab, not a `tab.close()`, and the window has onClose listeners (`fireClose()`). Not vetoed -> super `performClose:`. `NSWindowWillCloseNotification` -> `onWillClose` -> `markTabClosing` (synchronous), then `onClosed` deferred `setTimeout(0)` inside an autorelease pool, followed by `release(window)`. `onClosed`: detachPage, dispose webview and wrapper, emit `onTabClose`, `forgetPage`; when the host is empty: `fireClose()` or, with no listeners, `window.dispose()`.
- `tab.close()`: shown -> `performClose:` with `closingByApi` true (so never vetoed, last tab included). Unshown -> synchronous teardown, `group.discard`, `onTabClose`, and empty-host close as above. `tab.dispose()` = `tab.close()`.
- Reordering: AppKit tab bar (no code in the driver; unclear from the code whether order is tracked — `host.tabs` is a Map in insertion order).
- Tear-off: AppKit "Move Tab to New Window" or drag-out is handled by AppKit; the driver does not observe it (unclear from the code how a user tear-off maps to a new logical host). `tab.moveToNewWindow()`: unshown -> shown standalone; shown -> `moveTabToNewWindow:`; then a new `Window({ tabs: true, title, bounds: current frame, appearance, icon, resizable, opacity, hideFromTaskbar, noActivate, min sizes, topmost })` bound to the same group (`bindHostToWindow`), marked visible, tab events forwarded to the source, record rehomed (stops resize gesture, resubscribes file drop, `rebindFileDrop`, level).
- Merge: `group.mergeAllWindows()` (`mergeAllWindows:` on current window); every other host sharing the group gives its tabs and pending shows to the target, then its `Window` is disposed and host disposed; target flushes pending shows if visible.
- New-window requests: one shared `SweetviewTabUIDelegate` implements `webView:createWebViewWithConfiguration:forNavigationAction:windowFeatures:`; returns nil always; for `^https?:` schedules `handler(url)` via `scheduleNativeTimeout(1)` (cancelled if the tab begins closing) which opens `{ url, after: tab }` in the tab's current host. File open panels forwarded to the previous UIDelegate, else completion called with nil.
- Failed loads: shared navigation delegate class `SweetviewTabNavigation` implements `webView:didFailProvisionalNavigation:withError:` and `webView:didFailNavigation:withError:`; ignores `NSURLErrorCancelled (-999)`; address from `userInfo` `NSErrorFailingURLStringKey`, then `NSErrorFailingURLKey`, then `webView.URL`; reason = `localizedDescription`; skipped for `about:`/`data:` or closed tab; `raw.setHTML(loadFailedPage(url || options.url, reason))`. No HTTP-status or epoch checks on macOS.
- Keyboard shortcuts: menu key equivalents above; no accelerator interception in code.
- Focus: `focusWebView` on show; noActivate uses `orderFrontRegardless`.
- DPI: none in the driver; `scale()` is 1.
- Resizing/moving: `NSWindowDidResizeNotification`/`DidMoveNotification` per tab window -> host `bounds` updated, host `onResize`/`onMove` fired. `Window.startResize(edge)` -> `startDarwinWindowResize` on active tab (10 ms NSTimer, min = host min sizes, bound to that window). `startDrag` -> `performWindowDragWithEvent:` with `NSApp.currentEvent`, only when the primary button is down. `minimize` -> `miniaturize:`, `toggleMaximize` -> `zoom:` (skipped if `resizable:false`), `isMaximized` -> `isZoomed`.
- Host `hide()` orders out every shown tab window; `show()` re-selects the active tab then flushes pending shows. `isVisible()` = not closed, visible flag, and an active tab exists.
- `current()` (group): key window if it is one of the group's shown windows; else the `tabGroup.selectedWindow` of the last selected (or last shown) tab.
- File drops: `setFileDropEnabled` subscribes each tab NSWindow via `subscribeDarwinFileDrop` (`registerForDraggedTypes: [public.file-url]`) delivering to the host's `fireFileDrop`.

## Behaviour: the unified Window class

- Header comments state the class replaces `NativeWindow` and `Overlay` (`N/window.ts` L1) and `win32/overlay.ts + win32/window.ts`, `darwin/overlay.ts + darwin/window.ts`. The `main` branch API was not read; a comparison with `createOverlayWindow`/`nativeWindow` beyond these comments is unclear from the code.
- Audit fixes named in comments (Windows L3-13): 2.1 idempotent dispose destroying owned HWND and cleaning maps/timers/subclasses/HICONs; default WM_CLOSE destroys/disposes instead of hiding; WM_DESTROY never calls `PostQuitMessage(0)`. 2.2 `isMaximized` via `IsZoomed` for framed; `toggleMaximize` uses `SW_MAXIMIZE/SW_RESTORE` framed and `Screen.of(hwnd).workArea` frameless. 2.7 hit-region timer killed on hide, `setHitRegions(null)`, `setClickThrough`, dispose. 2.12 `ensureWin32Init()` runs COM STA, per-monitor DPI v2, Win11 25H2 hidden first-window anchor before any window. macOS (L3-13): 2.1 idempotent dispose; 2.3 outer-frame bounds applied while hidden, options honored regardless of `frame`, drag-resize loop; 2.7 hit NSTimer invalidated when no hits; 2.9 `performClose:` intercepted on own NSWindow subclass without replacing `delegate`.
- One class for framed, frameless, transparent, tabbed, and wrapped windows; `tabs: true` dispatches to tab backends on both platforms.
- Always created hidden. Outer-frame coordinates on both platforms (top-left origin of primary; physical px Windows, points macOS).
- `onClose`: with ≥1 listener the window stays open; with none an owned window is disposed (Windows WM_CLOSE -> owner dispose; macOS `performClose:` -> owner dispose). Closing never ends the event loop.
- File drops onto the native window: Windows `DragAcceptFiles` toggled with first/last listener, `WM_DROPFILES` read with `DragQueryFileW`, always `DragFinish`; wrappers subclassed via `SetWindowSubclass` (not for a tab frame, which already handles `WM_DROPFILES`). macOS: Sweetview NSWindow subclasses implement `draggingEntered:`/`draggingUpdated:` (copy op 1 when listeners exist), `prepareForDragOperation:`, `performDragOperation:` reading `public.file-url` items -> `filePathURL.path`; registration `registerForDraggedTypes:`/`unregisterDraggedTypes` with first/last listener; `fromHandle` wrappers throw "file drops require a Sweetview-managed NSWindow". `Window.onFileDrop` keeps one native subscription per Window and notifies `onWindowFileDropListenersChange` hooks (used by `WebView.attach` to toggle webview surface drops).
- `startDrag` rules: Windows non-tabbed: `ReleaseCapture` + `WM_NCLBUTTONDOWN(HTCAPTION)` (no left-button check in `buildWindow`). Windows tab frame: requires left button down; optional `held` point repositions first. macOS: only when primary button down (`pressedMouseButtons & 1`), `performWindowDragWithEvent:` with `currentEvent`; comment says otherwise AppKit logs "Window move completed without beginning".
- `startResize`: Windows non-tabbed: 10 ms `SetTimer` loop with `GetCursorPos`, stops when `VK_LBUTTON` released, clamps to `minWidth/minHeight` or 160x120. Windows tab frame: OS resize via `WM_NCLBUTTONDOWN` with HT code; not when zoomed or not resizable. macOS: 10 ms NSTimer loop, same clamping; new gesture replaces old.
- `show()` Windows non-tabbed: restore if iconic else `SW_SHOW`/`SW_SHOWNOACTIVATE`; when not noActivate and not topmost, flips TOPMOST/NOTOPMOST and `SetForegroundWindow`; restarts hit timer. macOS: `makeKeyAndOrderFront:` + `activateIgnoringOtherApps:` or `orderFrontRegardless`.
- `setBounds`/`moveTo` on Windows reassert `HWND_TOPMOST` when topmost.
- `holdWindowNativeDispose`: dispose runs hooks and marks disposed immediately but defers backend dispose until all holds release.
- `preserveGeometry` (Windows only): snapshot `GWL_STYLE`, `GWL_EXSTYLE`, outer bounds; restore thunk reapplies them (`SWP_FRAMECHANGED` when styles changed) and lays out the child.
- Frameless owned macOS windows without `noActivate` use `SweetviewKeyWindow` (`canBecomeKeyWindow`/`canBecomeMainWindow` YES); frameless windows get no shadow and `CanJoinAllSpaces|Stationary|FullScreenAuxiliary` collection behaviour (also when topmost).
- `closeToTrayOnLastWindow` as in Public API.
- `dispose()` on a tabbed window on both platforms runs the driver's dispose hook first (registered via `onWindowDispose`).

## Callbacks from the OS into JavaScript

- Win32 window procedures (`JSCallback (u64,u32,u64,i64)->i64`): `SweetviewTabFrame` and `SweetviewTabPane` procs (tab-window.ts 313-336), kept in module array `kept` for the process; exceptions logged and fall back to `DefWindowProcW`. `SweetviewWindow` proc (win32/window.ts 375) and subclass proc (443, 6 args) are module singletons. Thread: UI thread (comments on docs: every Window method runs on the UI thread).
- Timer procs (`(u64,u32,u64,u32)->void`): resize and hit polling, singletons.
- WebView2 handler JSCallbacks: per handler interface, one set of four (`QueryInterface`, `AddRef`, `Release`, `Invoke`) created lazily and kept for the process (comment: "The callbacks live for the process (one set per interface)"). `Invoke(self, sender, args) -> S_OK` dispatches to the live handler's `invoke` keyed by object address; errors logged. Per-subscription handler objects are 8-byte `BigUint64Array`s holding the vtable pointer, with JS-side refcount; reclaimed when refcount reaches 0. Thread: unclear from the code (WebView2 events arrive on the UI thread via the message loop; not stated in comments).
- `onNewWindowRequested` invokes the app callback on `setTimeout(0)`; `onAcceleratorKey` action runs via `later` (`setTimeout(0)`); failed-load page is set synchronously in NavigationCompleted.
- ObjC method JSCallbacks: `makeTarget` callbacks (`v@:` + n `@`), retained in a module array; `ensureWindowSubclass` callbacks retained with `retainCallback`; UIDelegate `createWebView` returns `ID` (always NIL) and `runOpenPanel` returns void, both retained. All process-lifetime. Errors logged.
- `drainMainQueue` marker JSCallback (`(ptr)->void`) dispatched with `dispatch_async_f`; closed only if reached, else logs "the main queue did not drain" (and the callback is not closed).
- macOS `windowWillClose` -> `onClosed` deferred with `setTimeout(0)` inside `pooled`; `didBecomeMain` -> `keepTabBar` deferred `setTimeout(0)`.
- Strip page -> JS: `__sweetview_rpc` uiMethods (via WebView.attach binding); JS -> strip: `emit("strip", state)`. Tab page -> JS: binding `__sweetviewTabTitle(title)` (URL tabs only); rename deferred via `later` on Windows, direct `setTitle` on macOS.

## State and lifetimes

Windows (`S/tabs/win-tabs.ts`):
- Module: `hosts: Map<Window, WinTabHost>`, `hostOrder: WinTabHost[]` (most recently activated first), `tabRecordByApi: WeakMap`, `nextTabId`, cached lib path. Native: `frames`, `frameApiByHwnd` (deleted on `WM_NCDESTROY`), `panes` set, `brushes` (never freed).
- `WinTabRecord`: id, title, window (host), pane HWND, webview, wrappedWin (`Window.fromHandle(pane)`), hooks, controller (cleared before webview destroy), cleanups, closed, api.
- `WinTabHost`: window, frame, tabs, selected, shown, strip webview, stripWin, stripController, stripCleanups, stripUp, active, scrolledBy, closed, baseTitle, stripReady, stopFrameCallbacks.
- Tab teardown order (closeTab/disposeHost): mark closed -> unlist -> hide pane -> controller = undefined -> run WebView2 handler removers -> `webview.dispose()` -> `wrappedWin.dispose()` -> `DestroyWindow(pane)` -> events.
- `disposeHost` order: mark closed, remove from maps, stop frame callbacks, splice tabs, tear down each tab (emit `onTabClose` per tab), strip cleanups -> strip dispose -> stripWin dispose -> `host.window.dispose()` (destroys frame and remaining child panes).
- `holdWindowNativeDispose` held during every strip/tab attach so `frame.destroy()` waits.
- Handler subscription: `subscribe` AddRefs the source (controller or core) and Releases it on removal; handler `dispose` drops our ref; removers must run before the webview is destroyed.
- `withCore` releases the `ICoreWebView2` after use; the subscription holds its own AddRef.

macOS (`S/tabs/darwin-tabs.ts`, `N/darwin/tabs.ts`):
- Module: `hosts`, `recordByNsWin`, `tabRecordByApi`, `activeGroupRefs: Map<WindowTabs, Set<MacTabHost>>`, counters. `hooksByWindow`, `sharedResponder`, `lastActiveGroup`. `pages: Map<Id, PageState>` (closing, detached, timers). `loadFailureHandlers`, `newWindowStates` (holds a retained previous UIDelegate).
- Group sets `shown`/`hidden`; identifier NSString retained until group dispose. Tab NSWindows are `+1` from alloc; released in `discard`, in the deferred `onClosed` path, or in group `dispose`.
- A group is disposed only when every host using it is closed and none has an attach in flight (`releaseGroupIfIdle`).
- `disposeMacHost`: for each tab: stop resize, detachPage, dispose webview, dispose wrapper; shown windows `close` (pooled), hidden ones `discard`; `forgetPage`; release group if idle.
- `detachPage` order: mark closing (cancel popup timers) -> remove load-failure handler -> `setNavigationDelegate: nil` -> restore previous UIDelegate and release it -> `removeAllScriptMessageHandlers` -> `stopLoading:` -> drain main queue twice. Called before `webview.dispose()` and from `beforeDestroy`; idempotent per window until `openPage`.
- Virtual window (`createVirtualTabbedWindow`) disposes controller then clears maps and buckets.

Window (`N/window.ts`):
- WeakMaps per Window for meta, backend, tab listeners, dispose hooks, holds, file-drop listeners/hooks; `ownedWindows` set.
- `dispose()` order: mark disposed, remove from owned, run dispose hooks (tab drivers tear down here, before listeners are cleared), clear tab listeners, unsubscribe native drop, clear file-drop maps, then backend dispose unless held (deferred to last hold release).
